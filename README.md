# Personal Portfolio
A personal portfolio website I developed from scratch to showcase my software development projects and web development skills.

**Live website**: https://kristinabatrak.com

## Features
- **Responsive design**: Uses CSS media queries to adapt the layout to different screen sizes.
- **Accessibility**: Uses semantic HTML and ARIA attributes to support accessible navigation.
- **Interactive introduction**: Includes a collapsible introductory section on smaller screens, implemented with JavaScript.
- **Project showcase**: Features my software development projects, with links to additional documentation and demos.

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)

## Running Locally
1. Clone the repository:
   ```git clone https://github.com/KristinaBBBB/Portfolio.git```
4. Open index.html in a web browser.

## About This Project
I built this website both as a place to showcase my work and as an opportunity to practice responsive web development without relying on frameworks. The design and implementation are my own, and I plan to continue updating the site as I complete new projects.
